# Decisions

| # | Topic | Decision and reason |
|---|---|---|
| 1 | Framework | Next.js 16.4.3 (App Router, TypeScript strict) from `create-next-app`. Scaffold defaults kept (Cache Components, partial prefetching, `@tailwindcss/turbopack`). The homepage is fully static, so they have no effect on this preview. |
| 2 | Tailwind | Tailwind v4, CSS-first. Tokens live in `@theme` in `src/app/globals.css`, not in a config file. Default colors, shadows, drop shadows, and blur are reset so only brand tokens compile. Gradients cannot be disabled by theme, so they are excluded by review. |
| 3 | Token names | Tailwind v4 names them `--color-obsidian`, `--color-off-white`, `--color-charcoal`, `--color-concrete`, `--color-graphite`, `--color-line-light`. v3 Section 4.5 used `--obsidian` and so on. The semantic variables `--bg`, `--fg`, `--fg-muted`, `--border`, `--radius` and the `.on-dark` class follow v3 exactly. Radius is `rounded-control` (2px). |
| 4 | Fonts | `next/font/local` with Latin variable WOFF2 files copied from the Fontsource packages into `src/fonts/` (OFL licenses beside them). The packages are not dependencies. Only Archivo is preloaded (sent as a `Link` header), as in v3 Section 4.6. |
| 5 | Archivo width axis | Confirmed present (62% to 125%). v3 assumption A6 is resolved. The display headline uses `font-stretch: 125%`. |
| 6 | Font weight budget | Archivo with the width axis is 90 KB and Inter is 48 KB, 138 KB in total. The v3 estimate was 100 KB. The width-axis file was kept because the wide display setting is part of the design. A weight-only Archivo is 35 KB. Revisit with a real measurement in Phase F7. |
| 7 | Logo | The logo zip was not available. `public/logo/` is empty. Phase F3 builds a temporary CSS wordmark unless the SVG files are added first. The default Next favicon was removed. |
| 8 | Strings | `src/lib/ui-strings.ts` exists from F0. Its `setupCheck` group belongs to the temporary page and is removed in F6. |
| 9 | Typecheck script | `next typegen && tsc --noEmit`, because Next generates the route types that `LayoutProps` needs. |
| 10 | Static export | Not enabled. `next build` already prerenders the page as static. |
| 11 | Browser check | Headless Chromium through `puppeteer-core` and `@sparticuz/chromium`, installed outside the repository. They are not project dependencies. |
| 12 | `AGENTS.md` | Generated by Next.js, which re-adds it on `next dev`. Kept. |

## Phase F3 (2026-10-29)

22. **Header.** One `Header` component. `overlay` mode (home): transparent over the hero, white text, no logo (the large hero logo is the logo). Default mode (other pages): solid Off-White with the logo. 56 px mobile, 64 px desktop, not sticky. It sits outside `<main>` so it is the page banner landmark.
23. **Mobile menu.** Native `<dialog>` with `showModal()`: the browser provides the focus trap, Escape, and an inert page behind it. Focus returns to the "Menu" button in the `close` handler. 200 ms fade-in only. Links close the panel on click.
24. **Stand-in page.** An explicit route `/not-in-preview` instead of a catch-all `[...slug]`, because a catch-all adds dynamic-params rules under Cache Components. Unknown URLs show the 404 page, which links home.
25. **Footer year.** Computed in a `"use cache"` server function so `new Date()` is allowed during static rendering. Check that it builds. If it errors, wrap `<Year />` in `<Suspense>` instead.
26. **Logo in footer and 404.** The orbit mark alone is not available, so the full logo is used (smaller). Swap when the mark file exists.
27. Not verified: build, typecheck and keyboard pass (no network in the build environment). The keyboard pass for the menu must be done on a real browser.

## Phase F4 (2026-10-29)

28. **Hero art direction.** `getImageProps` + `<picture>`: a 4:5 crop (`hero-mobile.jpg`, 651x814, 56 KB source) below 768 px, the wide photo from 768 px. The crop is taken from the same photo, centered on the model. The 150 KB mobile target is expected to be met after Next optimization (measured in F7). A plain `<img>` is used inside `<picture>` with an ESLint exception, because that is the documented Next pattern.
29. **The Drop.** Server section `drop.tsx` plus a client `product-grid.tsx` that holds only the category filter. Category controls are buttons with `aria-pressed`. The selected one is underlined (not color alone) and read as "Selected" by screen readers.
30. **Prices.** Formatted by `src/lib/format.ts` as "EGP 1,100" with a fixed locale. The plan's `Intl en-EG` currency format was skipped because its output differs between browsers and could cause hydration mismatches.
31. **Card hover.** The second image fades in on `group-hover`. Tailwind v4 only applies `hover:` on hover-capable devices, which satisfies the plan rule.
32. Not verified: build, LCP, layout shift, grid columns at each width (no network in the build environment).

## Motion (2026-10-29, owner request)

40. **Hero logo.** `animated-logo.tsx`: wipe in (1 s), hold (3 s), wipe out (1 s), repeat forever, so one cycle is exactly 5 s. A flat Off-White edge rides the wipe. No gradients. The logo also drifts up and fades on scroll.
